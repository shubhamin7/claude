# Memory market briefing: week of 2026-11-16

## Exit trigger (greenfield NAND/DRAM fab commissioning): **NO** (two items to watch)
- **Solidigm (SK hynix) two NAND fabs in Marcy, NY**: about $45B, possibly growing to about $100B; first fab sized at about 100k wafers/month. This is **greenfield NAND**, but it is still only a plan. No decision has been made, and it is stalled because the US has not approved export licenses for SK hynix's Dalian fab, which is meant to help fund it. Reported by Reuters on 2026-11-03 and TrendForce on 2026-11-04. Nothing new was reported this week. The last log entry (11-09) missed it.
- **SK hynix Yongin Y1 (greenfield DRAM)**: 89% built. The front-end DRAM cleanroom is still set to start operating in Feb 2027, a date moved up from May 2027 back in Feb 2026. This is a status check on an announced schedule, not new capacity (Seoul Economic Daily, 2026-11-16).
- Samsung's 11-12 groundbreaking at Onyang is an **HBM packaging/back-end** plant (46T won, operating by June 2028), not wafer capacity (Korea JoongAng Daily).
